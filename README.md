## 🔍 Key Insights
- 🔴 33.6% Abnormal test results
- 🟡 January = Peak month (816 patients)
- 🟢 Insurance evenly split (5 providers ~20% each)
- 🟢 Arthritis most common condition (9,308 cases)
- 🟡 Obesity = Highest avg billing Rs.25,806
